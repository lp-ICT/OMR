聖公會李炳中學 — 多項選擇題光學辨識系統 (OMR)

首次使用：在 Windows 安裝 Python 3.11 或更新版本，並確保首次啟動時可安裝 requirements.txt 的套件。雙擊「啟動_Windows.bat」；之後瀏覽器會開啟 http://127.0.0.1:8765/ 。程式只在本機運行；不用上傳答卷到網上。

使用方法：匯入多頁掃描 PDF（此版專為 2026 年 F5ICT 答案紙設計），選擇第一頁是否為標準答案；核對標準答案；匯入 CSV 學生名冊（欄名：班別,學號,姓名），逐張檢查待覆核題目與身份；匯出 Excel。

標準答案可逐題手動輸入，空白代表該題不計分。匯入答卷時可指定旋轉角度；掃描檔應為 A4、每頁一份答案紙、方向一致。身份配對只依賴學號塗格和名冊；手寫姓名、班別須人手確認。漏答、多選、擦改與低信心題目會標示待覆核，絕不自動當作肯定答案。老師可點選答案作覆核；保留原辨識結果和手動更改紀錄。

限制：此版只有固定 F5ICT 樣式的 60 題模板；未測試其他印刷樣式、嚴重透視變形或摺痕。可在預覽中對照每頁；若紙張偏位、辨識大量異常，請重掃，勿直接採納結果。資料保存在同資料夾下 data；如在共用電腦使用，請妥善保管該資料夾。
